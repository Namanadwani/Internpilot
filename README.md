# InternPilot

Helps students find internships: upload a resume, get feedback and best-fit
fields, see matched internships with a match score, approve a tailored email,
and send it from your own Gmail.

InternPilot never messages anyone on social media and never mass-mails resumes.

## Running it

```bash
npm install
npm run dev
```

Then open <http://localhost:3000>.
